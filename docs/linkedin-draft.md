# Rascunho de apresentação

Formscope: construtor de formulários com C#, ASP.NET Core 10 e Entity Framework Core.

A aplicação permite criar perguntas de texto, email e múltipla escolha, publicar um link e acompanhar as respostas em uma área privada. As perguntas ficam fixas após a publicação para preservar o significado dos dados recebidos.

O backend valida respostas, bloqueia mudanças desatualizadas e protege reenvios com chaves de idempotência. O repositório inclui testes de domínio, persistência e navegador, além de capturas de tela e instruções para executar localmente.

Código: https://github.com/SamirGedeon/formscope
